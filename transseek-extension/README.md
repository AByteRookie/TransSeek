# 深译 TransSeek 划词翻译（浏览器扩展）

在任意网页选中文字即可弹出「译」按钮，点击后调用本地 TransSeek 服务快速翻译。
适合阅读论文、文档、外文网页时随手划词/划句翻译。

## 工作原理

- 内容脚本监听网页中的文字选中，弹出「译」按钮与结果弹窗。
- 后台 Service Worker 把翻译请求转发到本地服务 `http://127.0.0.1:9177/translate`。
- 翻译本身由本地 TransSeek 服务完成（复用已配置的 DeepSeek API Key）。

> 因此使用前请确保本地 TransSeek 服务已启动（双击项目根目录的
> `start-transseek.vbs`，或依赖已配置的开机自启）。

## 安装（Chrome）

1. 打开 `chrome://extensions/`。
2. 打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录（`transseek-extension`）。
4. 完成后任意网页选中文字即可看到「译」按钮。

## 安装（Edge）

1. 打开 `edge://extensions/`。
2. 打开左侧「开发人员模式」。
3. 点「加载解压缩的扩展」，选择本目录（`transseek-extension`）。
4. 完成后任意网页选中文字即可看到「译」按钮。

## 设置

点击扩展图标即可打开设置页，可修改本地服务地址（默认 `http://127.0.0.1:9177`）。

## 已知限制

- 浏览器内置 PDF 阅读器、以及 `chrome://` / `edge://` 内部页面无法注入，选中无效。
- 网页内嵌 iframe 已覆盖（`all_frames: true`），但受站点安全策略限制的框架可能无法注入。
